What the transport tests covered
------------------------------
- POST /mcp initialize with requested protocolVersion 2025-03-26 returns 200 text/event-stream, result.protocolVersion 2025-11-25, serverInfo hearthkeep 0.1.0, and a UUID v4 Mcp-Session-Id. The SSE block is a single message event and has no event id.
- notifications/initialized on that session returns 202 with an empty body.
- tools/list returns 200 text/event-stream and result.tools [].
- With HK_JSON_RESPONSE=1, initialize and tools/list return application/json, and the negotiated version is still 2025-11-25. A missing MCP-Protocol-Version header is accepted.
- OPTIONS /mcp for an origin in HK_ALLOWED_ORIGINS returns 204. CORS allows methods POST, GET, DELETE and headers Content-Type, Accept, Mcp-Session-Id, MCP-Protocol-Version, Authorization. Access-Control-Expose-Headers is Mcp-Session-Id.
- An origin outside the allowlist returns 403 with a JSON-RPC error body and no Mcp-Session-Id.
- An allowlisted initialize response echoes that origin and still negotiates 2025-11-25 when the client requests 2024-11-05.
- GET /mcp returns 405.
- A non-JSON Content-Type returns 415. Accept without both application/json and text/event-stream returns 406.
- Unparsable JSON returns 400 with error code -32700. A JSON array returns 400 with error code -32600.
- tools/list without Mcp-Session-Id returns 400. MCP-Protocol-Version 2025-03-26 after initialize returns 400.
- DELETE /mcp for a live session returns 200. A later tools/list or DELETE with that id returns 404.
