# Data notice

Fictional data. Hearthkeep does not ship real personal data, real orders, real prices, or real provider accounts.

Every name, address, appliance, brand, price, and appointment added under `data/seed/` is invented for the simulation. Each seed file opens with this fictional-data notice, and the invented names are listed in that file. The simulator and every card show a "Fictional data" chip once those screens exist.

The demo purchase code `2468` confirms a mock payment only. It is not a credential for any real system.
