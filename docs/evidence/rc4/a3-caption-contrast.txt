Method
  One frame from the encoded mp4, inside each cue, at 30 fps. Frame number is time_s * 30.
  The caption box is the neutral near-black region in the bottom band (y >= 900): max channel <= 40, chroma <= 14, relative luminance < 0.02.
  Glyph pixels inside that box have every channel >= 230 and relative luminance >= 0.90.
  median_contrast is WCAG 2.1 between the median glyph RGB and the median box RGB.
  sample_contrast is one glyph pixel and a box pixel 8 to 14 px above it.
  glyph_vs_page is the same glyph median against pixel (24,24), which is the page or title card with no box. That is the old failure (about 1.11:1 on #F3F4EA). The pass number is the glyph against the box behind it.
  Relative luminance uses the sRGB linearization in WCAG 2.1. Pass means both ratios are at least 4.5:1.
