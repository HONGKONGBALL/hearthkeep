# Feature requests

No feature request is filed.

The product plan listed four candidates: a device-free Alexa+ test console that can attach a self-hosted Streamable HTTP MCP server, a published matrix of MCP features the Alexa+ host supports, a sandbox purchasing mode, and a reference kit for the simulated-experience path. None of those is filed here. This build did not record a friction entry of attempting that host and hitting one of those gaps. The simulated path was chosen from the hackathon brief because no Echo or Alexa+ device was available, before any attach attempt.

Friction that did happen is in `docs/friction-log.md`. FL-01 through FL-06 are about the local test runner, the local MCP server, Playwright logs, stale docs, and the DashScope key file. They do not support an Alexa+ host request.
