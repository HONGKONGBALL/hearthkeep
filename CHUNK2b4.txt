The app reads HK_DB and HK_SIM_MODE. HK_SIM_MODE defaults to on. The exact value 0 turns sim mode off.

In sim mode, GET /sim/state returns the snapshot (clock, appliances, schedule, inventory, orders, bookings, tasks, audit). POST /sim/clock accepts {advanceDays: 1-400} or {set: ISO time later than now} and returns 200 {now}. Other bodies return 400. POST /sim/reset returns 200 {now: 2026-10-21T09:00:00-07:00, seed: v1} and reseeds state with sequential ids. /sim outside sim mode is 404. /sim uses the same Origin allowlist as /mcp. An empty database loads seed v1 on first start. Session ids stay random.

scripts/smoke.mjs initializes a session, lists tools, and calls get_upkeep_status.
